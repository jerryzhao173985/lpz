# Journey Documentation Archive

This directory contains historical documentation that chronicles the modernization journey of the LPZRobots project from C++98/Qt4 to C++17/Qt6.

## ⚠️ Important Notice

**These documents are historical records and should NOT be used as current project status references.**

For current project status, please refer to:
- `/SOURCE_OF_TRUTH.md` - Authoritative current status
- `/README.md` - User-facing documentation
- `/CLAUDE.md` - AI assistant guidelines
